## Questions and Answers

### Question 1: Matching Define-Step Elements

**Question:** Match the elements from Phase 2 (Digital Entrepreneurship) to their corresponding elements in the Define step.

- **Target Market** → User
- **Value Proposition** → Problem Statement

**Answer:**
- Target Market: User
- Value Proposition: Problem Statement

### Question 2: Acceptable Prototype

**Question:** According to the speaker, what is an acceptable prototype at this stage?

- a. Paper sketches of app screens
- b. A database system
- c. A functional app store download
- d. A programmed script

**Answer:** a. Paper sketches of app screens.

### Question 3: Testing a Prototype

**Question:** How do you conduct the Test step using your prototype?

- a. By showcasing your paper prototype to real people and watching them interact with it
- b. By running automated software tests
- c. By submitting source code for review
- d. By pitching the app directly to investors

**Answer:** a. By showcasing your paper prototype to real people and watching them interact with it.

### Question 4: User-Centred Design

**Question:** User-centred design means that decisions about app screens, buttons, and features are based on what?

- a. The latest design trends in popular apps
- b. What the person who is going to use it actually needs
- c. The fastest code implementation method
- d. What the developer personally thinks is cool

**Answer:** b. What the person who is going to use it actually needs.

### Question 5: Common Beginner Mistake

**Question:** What is the biggest mistake that most beginner programmers or developers make?

- a. Building something that nobody wants
- b. Choosing the wrong programming language
- c. Forgetting to market their application
- d. Writing inefficient code

**Answer:** a. Building something that nobody wants.

### Question 6: The Define Phase

**Question:** What is the main goal of the Define step in Design Thinking?

- a. To explicitly define the problem you are trying to solve in a problem statement
- b. To write the source code for the app
- c. To generate as many app ideas as possible
- d. To draw visual prototypes of app screens

**Answer:** a. To explicitly define the problem you are trying to solve in a problem statement.

### Question 7: The Ideate Phase

**Question:** Which step in Design Thinking involves generating multiple ideas and evaluating which ones are realistic to build within your time limit?

- a. Define
- b. Ideate
- c. Prototype
- d. Empathize

**Answer:** b. Ideate.

### Question 8: The First Phase

**Question:** Which step is the very first phase in the five-step Design Thinking framework?

- a. Define
- b. Prototype
- c. Empathize
- d. Ideate

**Answer:** c. Empathize.

### Question 9: Prototyping

**Question:** At the prototyping stage in this unit, a prototype must be a coded application.

- True
- False

**Answer:** False.

**Explanation:** A prototype can be a simple paper sketch of app screens. It does not need to be a fully coded application.

### Question 10: Empathizing with Users

**Question:** During the Empathize phase, you should rely on your personal assumptions about the user rather than talking directly to them or observing them.

- True
- False

**Answer:** False.

**Explanation:** The Empathize phase requires you to speak directly to users, observe their behaviour, and understand their actual needs instead of relying on assumptions.

## Key Learning Points

The five phases of Design Thinking are:

1. **Empathize** — Understand users and their needs through observation and conversations.
2. **Define** — Identify the main problem and write a clear problem statement.
3. **Ideate** — Generate and evaluate possible solutions.
4. **Prototype** — Create a simple representation of a proposed solution.
5. **Test** — Let real users interact with the prototype and gather feedback.

## Conclusion

Design Thinking encourages developers to understand users before building solutions. By defining the right problem, exploring ideas, creating prototypes, and testing them with real people, developers can create products that better meet users' needs.
