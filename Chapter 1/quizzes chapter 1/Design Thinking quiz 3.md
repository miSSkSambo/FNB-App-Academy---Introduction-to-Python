# Inclusive Design and Wireframes — Quiz Questions and Answers

## 📘 Overview

This quiz covers the fundamental principles of **inclusive design, wireframing, accessibility, and data efficiency**. It explores how to design user-friendly applications that meet the needs of diverse users, particularly in the South African context.

## 🎯 Learning Objectives

- Understand the purpose of wireframes.
- Apply inclusive design principles.
- Recognise the importance of font size, colour contrast, and plain language.
- Understand data-efficient design.
- Identify essential features of an application.
- Plan app screens and user flows.

---

## 📝 Quiz Questions and Answers

### Question 1: What is a wireframe?

**Answer: B — A simple, low-detail visual plan of a screen.**

A wireframe shows the basic layout and structure of an application before detailed design or development begins.

### Question 2: What is the recommended minimum font size for body text?

**Answer: B — 12 points.**

Body text should be large enough to read comfortably. The appropriate size may vary depending on the device and audience.

### Question 3: Which is an example of plain language?

**Answer: D — Search.**

Plain language uses simple, familiar words that users can understand easily.

### Question 4: Which is an example of a plain-language button label?

**Answer: B — Back.**

Short and familiar labels help users understand what an action will do.

### Question 5: What does data efficiency mean in app design?

**Answer: D — Designing apps to minimise unnecessary data usage.**

Data-efficient applications reduce unnecessary downloads and help users with limited mobile data.

### Question 6: Which design decision supports data efficiency?

**Answer: B — Reducing large images and videos.**

Optimising media can reduce loading times and mobile data consumption.

### Question 7: What is a must-have feature?

**Answer: A — A feature necessary for the app to function effectively.**

Must-have features are essential to the application's main purpose.

### Question 8: Which principle supports inclusive design?

**Answer: A — Data efficiency.**

Data efficiency helps make applications more accessible to users with limited connectivity or mobile data.

### Question 9: Why is colour contrast important?

**Answer: A — It helps distinguish text from the background.**

Good contrast improves readability, including for users with visual impairments.

### Question 10: Why should designers limit large images and videos?

**Answer: C — They increase data consumption.**

Large media files can use substantial mobile data and make applications slower to load.

### Question 11: Which are principles of inclusive design?

**Answers: A, B, C and F — Contrast, Data Efficiency, Plain Language and Font Size.**

These principles help make applications easier to access and use for people with different needs.

### Question 12: What do wireframes mainly focus on?

**Answer: B — Layout and screen structure.**

Wireframes show where elements such as buttons, headings, images and navigation will appear.

### Question 13: What should be included in a capstone app design brief?

**Answers: A, C, D, E, F and G.**

- Target user
- Inclusive design considerations
- Problem statement
- Three core features
- Build plan for Weeks 8 and 9
- Screen flow sketch

These elements help define the application's purpose, users, design requirements and development plan.

### Question 14: What is sufficient for a basic wireframe?

**Answer: C — Boxes, labels and arrows.**

Simple shapes and labels can communicate screen layout and navigation without requiring a finished design.

### Question 15: Which tool was demonstrated for creating wireframes?

**Answer: B — Figma.**

Figma is a design tool that can be used to create wireframes and interactive prototypes. Confirm this answer against your course presentation.

### Question 16: Why is inclusive design essential in South Africa?

**Answer: B — Because of diversity in culture, language, ability and technology access.**

Inclusive design considers the different backgrounds, abilities and technology limitations of users.

### Question 17: What is the purpose of colour contrast?

**Answer: C — To ensure text can be distinguished from the background.**

Appropriate contrast helps users read text and identify important interface elements.

### Question 18: Which design choice creates poor readability?

**Answer: C — A white background with very light grey text.**

The low contrast makes the text difficult to read.

### Question 19: Why is font size important in inclusive design?

**Answer: D — People have different eyesight and readability needs.**

Appropriate font sizes help users read content comfortably across different devices and abilities.

### Question 20: Is Figma the only tool that can be used to create wireframes?

**Answer: False.**

Wireframes can be created using other design tools or even paper sketches, unless a course specifically requires a particular tool.

---

## ✅ Key Takeaways

- Wireframes provide a basic visual plan of an application's screens.
- Inclusive design considers different user needs and abilities.
- Good contrast and readable font sizes improve accessibility.
- Plain language makes applications easier to understand.
- Data-efficient design helps users with limited mobile data.
- A clear problem statement, target audience and screen flow support effective app planning.

## 📚 Conclusion

Inclusive design and wireframing are important steps in developing accessible, practical and user-friendly applications. By applying these principles, developers can create digital solutions that work better for a wider range of users.
