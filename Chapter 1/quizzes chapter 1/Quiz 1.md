## Key Concepts Learned

- **Functions:** Reusable blocks of code that perform specific tasks.
- **Parameters:** Placeholders defined in a function's parentheses.
- **Arguments:** Actual values supplied when calling a function.
- **`def`:** The keyword used to define a function.
- **Indentation:** Python uses indentation to identify the function body; four spaces is the standard convention.
- **`return`:** Sends a value back to the code that called the function.
- **`print()`:** Displays output in the terminal.
- **Methods:** Functions associated with objects or classes.
- **Function calls:** Execute a function by writing its name followed by parentheses.

## Example Python Function

```python
def vat_calculator(amount):
    vat = amount * 0.15
    return vat

result = vat_calculator(100)
print(result)
```

**Output:**

```text
15.0
```
