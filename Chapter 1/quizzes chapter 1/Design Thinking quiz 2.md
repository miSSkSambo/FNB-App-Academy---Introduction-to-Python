# Design Thinking Quiz 2: App Prototype Design

---

## Questions and Answers

### Question 1: Matching Prototype Screen Layouts

**Question:** Match each prototype screen layout to the information it displays.

| Prototype Screen | Correct Answer |
|---|---|
| About Screen | Background information regarding the app's purpose |
| Home Screen | Local event titles and category filter buttons |
| Event Details Screen | Address, time, organizer, and detailed event description |

### Question 2: Core App Solution

**Question:** During the evaluation step, which feature was selected as the core solution for the app?

- a. Map view of the entire location
- b. Built-in event reminder system
- c. Simple list of events sorted by date
- d. Video promotion player

**Answer:** c. Simple list of events sorted by date.

### Question 3: Choosing a Date-Sorted List

**Question:** Why was a date-sorted text list chosen over an interactive map view during the design evaluation phase?

- a. Text lists are simple to build and consume very little mobile data
- b. Maps are not supported on modern mobile devices
- c. Text-only interfaces allow video playback at higher resolutions
- d. Users requested interactive map routing over simple dates

**Answer:** a. Text lists are simple to build and consume very little mobile data.

### Question 4: Problem Statements

**Question:** According to the design walk-through, what essential elements must a well-defined problem statement include?

- a. The specific target user group and their explicit problem
- b. The app logo artwork and server configuration
- c. A complete list of all secondary features
- d. The budget cost and the coding language used

**Answer:** a. The specific target user group and their explicit problem.

### Question 5: Creating a Prototype

**Question:** What medium are viewers instructed to grab to draw at least one screen layout for their app concept?

- a. A digital tablet app
- b. A piece of paper
- c. A vector editing software
- d. A database management tool

**Answer:** b. A piece of paper.

### Question 6: Target Users

**Question:** Who is the primary target user profile for the app's initial design phase?

- a. High-income tourists visiting city centres
- b. Event organizers looking to sell high-priced tickets
- c. Young people aged 16 to 25 living in townships
- d. Working professionals seeking remote jobs

**Answer:** c. Young people aged 16 to 25 living in townships.

### Question 7: Value Proposition

**Question:** What is the primary value proposition of the app concept?

- a. Social networking and live chat with event organizers
- b. High-definition video streaming of local concerts
- c. Data-light community event discovery
- d. Advanced GPS navigation for township routes

**Answer:** c. Data-light community event discovery.

### Question 8: Design Thinking and Entrepreneurship

**Question:** Design thinking and entrepreneurship should be treated as separate, unrelated concepts.

- True
- False

**Answer:** False.

**Explanation:** Design thinking helps entrepreneurs understand user needs, identify problems, and develop practical solutions that can create business opportunities.

### Question 9: Event Reminders

**Question:** Built-in event reminders were included in the core prototype screens because users cannot set alarms or reminders on their phones.

- True
- False

**Answer:** False.

**Explanation:** Users can set alarms and reminders on their phones. The core prototype prioritises essential event discovery features.

### Question 10: Community Event Discovery

**Question:** Relying on WhatsApp groups and word of mouth often causes users to miss events because they find out about them after they happen.

- True
- False

**Answer:** True.

**Explanation:** Information shared through informal channels may reach users too late, making it difficult for them to discover and attend events in time.

## Key Learning Points

- **Target users:** Identify the people the app is intended to serve.
- **Value proposition:** Explain the main benefit the app offers its users.
- **Problem statement:** Clearly describe the target user and the problem that needs solving.
- **Prototyping:** Use simple sketches to plan and communicate an app's layout.
- **User-centred design:** Prioritise real user needs when selecting features.
- **Data efficiency:** Consider mobile data usage when designing apps for communities.
- **Design thinking and entrepreneurship:** Apply user research and creative problem-solving to develop useful solutions.

## Conclusion

This quiz demonstrates how design thinking can guide the development of a practical, user-centred community event discovery app. By focusing on the target audience, essential features, simple prototypes, and data-light design, developers can create solutions that address real community needs.
